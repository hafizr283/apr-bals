CONCLUSION (2026-08-04)
========================================================================================================
1. The "25-37% occupancy loss" is CONFIRMED exactly: 0 / 0 / 25.0 / 37.5 / 37.5%.
   BUT it holds only because BOTH legs are register-limited to exactly ONE resident block
   per SM (~64 regs x 1024 threads), which is what makes block size pass straight through
   to resident warps. Quote the number only with that condition stated -- "smaller block
   => lower occupancy" is NOT true in general, and asserting it is the same error that was
   made for TF32 and withdrawn (see ../theoretical_occupancy.txt / SUMMARY.md Item 3).

2. Occupancy is only HALF the mechanism. It explains K>=48, but FAILS at K=16, where the
   penalty is exactly ZERO and symtile still loses 0.878-0.930x.

3. The other half is triangular padding waste, which runs the OPPOSITE way with rank:
   3.20x at K=16 falling monotonically to 1.07x at K=96, while the occupancy loss rises
   monotonically from 0% to 37.5%.

4. K=32 is the ONLY rank where neither penalty bites -- block still full (0% occupancy
   loss) and waste already down to 1.78x -- and it is the ONLY rank where symmetric
   tiling wins. The published K=32 row is therefore not a representative sample of the
   sweep; it is the single point where both penalties happen to be small.
